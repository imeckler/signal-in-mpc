# Actual owned inner-response driver candidate

`replay.py` preserves the computational bodies of the extracted default Prost
Message merge loop and transferred owned-slice wrapper. It changes namespace,
imports and identical pinned primitive type aliases. `FunsExternal` supplies the
already extracted actual key decoder and executable Result.map. Canonical
contiguous buffers are the supported domain.

`DriverReference` installs the actual generated response field dispatcher,
proves key decoding totality and strict consumption on success, and projects
finite success/error field traces into the unchanged actual merge loop. The
owned wrapper preserves exact error contents and all outer failures/divergence;
it drops only the failed local message value. Unused encoding/clear trait slots
fail closed and are not invoked by the actual default merge body.

This is not yet a total full-schema theorem: trace existence, bounded allocation,
outer submessage/envelope, streaming invariants and compiler composition remain
open. The diagnostic static-reference push bridge and std UTF8/content model
boundaries from InnerResponseV1 remain explicit. No log-trace equivalence.

Run `python3 SignalReference/ChatResponseReferenceWork/InnerScanV1/check.py`.
The four-module check links verified ancestor objects into a separate output
and binds source/object hashes without rebuilding large ancestors.
