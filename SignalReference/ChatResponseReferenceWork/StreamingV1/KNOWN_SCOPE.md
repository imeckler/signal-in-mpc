# Actual scalar/body field scope joins

`native_body_header_scope` and `native_body_field_scope` prove exact child closure/remainder/depth and public budget after the actual body length/copy span. `actual_body_field_scoped` joins these to actual generated source Bytes replacement/content/suffix, body cache metadata, validity, key mode/zero skip and exact native copied-byte payload events. Empty/duplicate bodies and exact child end are included.

`ScalarScopeStep` and `native_scalar_scope` prove exact child closure/remainder/depth at the actual native scalar suffix, independent of numeric validity. `actual_scalar_field_scoped` joins source ID/status result, full64 ID/low32 status cache update, validity and complete varint control with exact public budget/private child scope on one consumed prefix.

Theorems keep the established bounded current-field entry relations and successful native decode/copy domain. They are successful-field branches for full scan, not a replacement for the separate all-outcome malformed/truncated/overrun/error source results. Full scan must derive key-entry relations and join those error branches, repeated HTTP headers, unknown fields/groups, schema/HTTP/correlation/private EOF/compiler endpoints. Source std UTF8/static diagnostic push/content allocation boundaries remain explicit. No runtime/generated computation edits or complete response claim.
