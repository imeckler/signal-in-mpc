# Actual inner-group close decisions: all outcomes

GroupMismatchClose derives the active parent slot from the recursive relation,
executes actual mismatched group body/loop error with exact native suffix, and
proves full Core rejection even for a key crossing the private child.

GroupPopBoundary preserves actual source matching group success/suffix at/past
the private child. Core rejects an overrun or an exact child end leaving another
enclosing group active. It does not invent a source error or equate source and
numeric rejection cursors: a source ancestor may still continue afterward.

GroupCloseAttempt joins matching, mismatched and all private-end compatibility
decisions into one theorem, deriving the decisions rather than supplying them.
Source group body and loop always retain the exact real groupClose result.
Successful numeric continuation restores the enclosing witnessed stack/context
or ordinary response key state; incompatible boundaries and mismatches reject.

Inputs are the real successful native end-key run and live witnessed inner-group
relation/cache, with real private state/counters. Key termination/errors and other
wire classes are separate components. Fixed/length, recursive whole-group/full
scan/headers/outer/HTTP/correlation/compiler composition remain OPEN; this does
not claim entire response-source agreement. Inherited bounded content/allocation,
std UTF8 and static diagnostic-push boundaries remain explicit. No runtime/backend,
native execution or performance-export changes.
