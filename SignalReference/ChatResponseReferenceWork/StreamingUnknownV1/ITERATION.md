# Complete actual unknown-varint field iteration

This composes the real generated key call, default field branch, source native
varint decoder, borrowed callback and actual parent-limit loop. It does not
modify frozen proofs, translators or production parser/runtime. New source
context follows the pinned actual default/skip implementations.

KeyGuard derives unknown classification independently of validity/inner/depth,
and all common/native key checks with actual recursion guard. KeyValidity/Entry/
Ready derive exact consumed key, actual cursor, full bounded child/budget state,
unknown scalar lane and cache from actual key execution. No decoded table,
Core validity/recognition or primitive correctness is assumed at field entry.

Iteration proves fit success resumes the full ChildAtKey/cache/native suffix.
KeyBoundary covers a key exhausting or crossing its private child. ErrorIteration
preserves exact ordinary native errors and unchanged source record/suffix, and
proves Core rejection regardless of whether the key leaves value bytes. Overrun
retains a successful Prost callback consuming past the child in its parent
buffer, then proves the actual next loop step returns DelimitedLengthExceeded
with that later suffix. Numeric rejection can occur earlier; no cursor equality
is fabricated. FiniteRun closes the actual source loop result on both errors.

Attempt derives the native payload result exhaustively and joins success, native
error and child-overrun branches into one theorem. Its premises are actual
successful unknown-varint key execution, actual nonzero recursion context and
the existing bounded live ChildAtKey/cache invariant. No native payload success,
finite skip derivation or parser validity result is assumed. Previous all-input
primitive prefix/error correspondence remains explicit in the theorem.

Remaining: other wire classes (fixed/length/group/EndGroup), complete inner/outer
scan induction, repeated-header/HTTP validation and source correlation/compiler
composition. Source key-error rejection is separately proved in StreamingV1 and
not silently conflated with an unknown-tag key success. Std UTF8, bounded owned
content/allocation and static-reference diagnostic-push boundaries are unchanged.
This is a component closure, not complete actual response refinement.
