# Group opaque bytes and actual closing-source decision

GroupOpaqueProjection derives exact full-state depth-projection feed equality for
arbitrary opaque payload prefixes from strict private remaining bounds and actual
skip-mode control evolution. It covers the last payload byte. GroupOpaqueValidity
composes this equality with the checked opaque proof to preserve validity at the
real retained group depth. No per-byte mode, non-closing guard or validity oracle
is supplied; those guards are derived from count/remaining and actual controls.

GroupCloseSource executes the unchanged actual generated unknown/default group
merger when its next key is an end tag. Matching and mismatched closes retain their
exact actual native result, message and post-key suffix. Its guard theorem relates
the source close outcome to the actual Core active-parent comparison, using the
proved bounded stack lookup. Closing at maximum depth remains possible.

This is not a complete group theorem. Native key-prefix/terminal alignment, the
recursive source-context/active-stack invariant, private child group transitions,
whole group/scan/headers/outer/HTTP/correlation/compiler composition remain OPEN.
Explicit strict payload fit leaves room for the required end tag. Source close
composition inputs include the real key run and witnessed active parent slot;
no parser correctness assumption or new axiom is introduced. Inherited bounded
content/allocation, std UTF8 and static diagnostic-push boundaries remain explicit.
No runtime/backend edit, native benchmark or performance export.
