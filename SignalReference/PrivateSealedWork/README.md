# Variable-prefix SSv1 candidate

One CTR/KDF/HMAC path accepts a shared inner Signal length. Canonical protobuf
lengths, private HMAC padding and encrypted-message length are carried into
one fixed public-capacity envelope; rejection remains distinct from empty.
Eight public native-generated-DH fixtures match actual pinned libsignal SSv1
across inner lengths0..80 and four malformed/binding cases reject. This suite
supplies actual DH test values; it does not execute private DH in native MPC.

Three standard-axiom kernel endpoints establish concrete-model compiler
agreement. Integer buffer/protobuf/private-hash semantics and full actual
Rust/Aeneas refinement remain unproved. The cap80 artifact has10,046,800
numeric AIG nodes (227MiB JSON); no native compilation or throughput claim.
General packing currently repeats normalization checks and needs optimization.
